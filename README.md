# 📁 Version Control Management – DSA Project

This project is a **Version Control System** built using **C language** and **Data Structures**. It mimics the core functionalities of modern version control tools like Git and Github offering file tracking, versioning, and basic repository management from scratch. This was developed as a part of our **Data Structures and Algorithms (DSA)** coursework for Subject Data Structures and Algorithm.

---

## 🧠 Features

- 🗃️ **Repository Initialization**  
  Create a new repository and set up tracking for files.

- 📝 **File Creation and Editing**  
  Create and modify files with tracking.

- ⏮️ **Commit Management**  
  Store and retrieve previous versions using commit history.

- 📜 **History Tracking**  
  Traverse through commit logs to see past changes.

- 🔄 **Revert to Previous Versions**  
  Switch back to older versions of files safely.

- 📂 **Data Structures Used**  
  Efficient use of Linked Lists, Stacks, and Queues to simulate version management.
